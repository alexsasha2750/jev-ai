# Jev AI

Браузерный интерфейс для принятия структурированных решений с помощью Jev через Pollinations.

Jev — первая модель **System One** от TypeSafe AI. В отличие от традиционных LLM, ориентированных на чат и свободный текст, Jev предназначен для выдачи **типизированных решений, которые можно напрямую обрабатывать программным кодом**. Приложение передаёт состояние и типизированные вопросы, а Jev возвращает структурированные ответы: варианты, оценки и вероятности «да/нет», а там, где это поддерживается, — информацию об уверенности.

> **Примечание:** этот репозиторий является независимым клиентским интерфейсом. Он не является официальным продуктом или официальным сайтом TypeSafe AI.

## Что такое Jev?

TypeSafe AI позиционирует Jev как модель принятия решений для автоматизации программного обеспечения. Основная идея проста: **решения, а не строки текста**.

Вместо того чтобы просить генеративную модель написать ответ, а затем пытаться извлечь из текста нужные данные, приложение может заранее определить форму результата. Jev оценивает переданное состояние в соответствии с типизированными вопросами и возвращает структурированные результаты, которые код приложения может использовать напрямую. TypeSafe AI описывает свой подход к обучению как **Reinforcement Learning for Calibrated Decisions (RLCD)**.

Типичные сценарии:

- **Классификация** — распределение запросов, тикетов или событий по заранее заданным категориям.
- **Оценивание** — оценка срочности, риска, качества и других упорядоченных показателей.
- **Бинарные решения** — оценка условий «да/нет» в виде вероятностей.
- **Ограничения для агентов** — проверка, можно ли автоматизированному действию продолжить выполнение или требуется проверка.
- **Маршрутизация моделей** — выбор подходящей модели или рабочего процесса.
- **Триаж задач** — преобразование состояния приложения в решения, которые существующий код может использовать.

Jev не предназначен для замены универсальных языковых моделей при написании текстов, суммаризации или свободном диалоге. Его задача уже: выдавать повторяемые структурированные решения, пригодные для использования программным обеспечением.

## Об этом проекте

**Jev AI** — лёгкое статическое веб-приложение, предоставляющее браузерный интерфейс для инференса Jev через Pollinations.

Приложение позволяет:

1. подключить аккаунт Pollinations или указать персональный API-токен;
2. ввести контекст приложения;
3. определить структурированные вопросы;
4. запустить инференс Jev;
5. посмотреть полученные решения, уверенность и распределения.

Всё работает в браузере. Система сборки и установка npm-зависимостей не требуются.

## Локальный запуск

Проект состоит из обычных HTML, CSS и JavaScript.

```sh
python3 -m http.server 8000
```

Затем откройте:

```
http://localhost:8000
```

Аутентификация и инференс выполняются через API Pollinations из браузера. Никогда не добавляйте персональные API-токены в репозиторий и не передавайте их другим людям.

## Структура проекта

- `index.html` — разметка и интерфейс приложения
- `styles.css` — визуальный дизайн, адаптивная верстка и улучшения доступности
- `app.js` — OAuth, работа с токенами, интеграция Pollinations и инференс Jev
- `assets/pollinations-logo-light.png` — логотип Pollinations
