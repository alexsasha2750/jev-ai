How to write questions

State: Put the facts Jev should use here.

Question: Ask one clear thing about those facts.

Choice: Enter all possible answers, separated by commas. Example: “What is 2 + 2?” with answers “4, 5”. For Correct/False, ask a claim: “Is 2 + 2 = 4?”

Score: Enter 2–10 numeric levels from 0 to 100, separated by commas. Example: “0, 25, 50, 75, 100”. Jev uses their distribution to estimate a score between levels.
